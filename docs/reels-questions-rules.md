# iqtest.live — Reels сұрақтарын құрастыру ережесі

## 1. Бір видеоның құрылымы (4 сұрақ)
| № | Деңгей | Мақсаты |
|---|---|---|
| 1 | Жеңіл — ~90% біледі | «Мен білемін!» сезімі → видеоны әрі қарай көреді |
| 2 | Жеңіл | Сенім, соңына дейін көру, лайк |
| 3 | Орташа — ~50% біледі | Ойландырады, қызығушылықты ұстайды |
| 4 | Комментарий сұрағы | Көпшілік «анық» жауапты таңдап, қателесетін таңғаларлық факт → комментарийде дауласады |

## 2. Мазмұн ережелері
- Тек даусыз, уақыт өте өзгермейтін фактілер (халық саны, қазіргі басшылар, жаңарып тұратын рекордтар — жоқ).
- Сұрақ нақты әрі өз алдына түсінікті: керек мәтінмән сұрақтың ішінде жазылады.
- Айла сөздер жоқ: «шын мәнінде», «на самом деле», жұмбақ, қос терістеу.
- Әр сұрақтың бір ғана дұрыс жауабы болады.
- Тақырыптар әр түрлі, бір видеода 4 бөлек тақырып: табиғат, ғарыш, география, тарих, ғылым, адам денесі, тағам, спорт, өнер, технология.
- Қазақстан туралы сұрақ — сирек (бір видеода ең көбі біреу).
- Көрерменге таныс тақырыптар; тар шетелдік тарих / спорт / поп-мәдениет — жоқ.
- Бұрын қолданылған сұрақтар қайталанбайды.

## 3. Пішімі
- 3 нұсқа, әрқайсысы ≤ 18 таңба; қате екеуі сенімді, күлкілі емес.
- Сұрақ мәтіні ≤ ~60 таңба.
- Дыбыстау мәтінінде сандар сөзбен: «26» → «жиырма алты».
- Эмодзи тек тақырыпты көрсетеді, жауапты ешқашан көрсетпейді.
- Сурет: сұрақта аталған зат немесе бейтарап көрініс; жауап, жалау, карта, жазу, сан — жоқ.

## 4. Тіл (қазақша)
- «қайсы?» емес → «қандай?»
- «туған» емес → «туылған»
- «аумағы бойынша» емес → «жер аумағы бойынша»
- Соңында: «Жауабыңызды комментарийге жазыңыз!»

## 5. Сұрақтар базасы (ЖИ-сіз)
- Файл: `admin/quiz-bank.json`, құрастырушы: `scripts/build-quiz-bank.py` (+ `scripts/quiz_facts_kz.py` — қолмен тексерілген фактілер).
- ~10 500 сұрақ: фактілер, елордалар, материктер, химиялық таңбалар, бірлік түрлендіру, арифметика, сандар қатары, амалдар реті, ондық бөлшектер, жай/тақ сандар. Математикалық сұрақтардың жауабы есептеліп шығарылады — қате болмайды.
- «📚 Создать из базы» әр видеоға 2 жеңіл + 1 орташа + 1 комментарий сұрағын, 4 түрлі тақырыптан алады; қолданылған сұрақ қайта шықпайды (≈1 600 видеоға жетеді).
- Жаңа факт қосу: `quiz_facts_kz.py` файлына жол қосып, `python3 scripts/build-quiz-bank.py` іске қосу.
