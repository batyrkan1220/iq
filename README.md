# MindMetric — тест IQ

Онлайн-тест IQ на русском и казахском языках (RU / ҚАЗ): 39 заданий — матрицы, аналогии, узоры, числа, память и логика.

## Структура

- `index.html` — готовый сайт одним файлом (его и нужно загружать на хостинг).
- `src/` — исходники:
  - `template.html` — разметка и стили;
  - `gen.js` — генератор фигурных заданий-матриц;
  - `i18n.js` — казахские переводы;
  - `app.js` — логика теста, оплаты и результата.
- `build.py` — собирает `index.html` из `src/`: `python3 build.py`.
- `assets/logo/` — логотип MindMetric (SVG и PNG).

## Деплой

Сайт статический: загрузите `index.html` в корень хостинга (например, `public_html` на ps.kz)
или подключите репозиторий к Render как Static Site с Publish Directory `./`.

## Что ещё не подключено

- Оплата через Kaspi (сейчас на экране оплаты демо-кнопка).
- Сервер и база данных для результатов и подтверждения оплаты.
